# Sources

## md-toc

https://pypi.org/project/md-toc/

`md-toc` is a Python package that builds contents lists for several Markdown
formats. Its GitHub mode handles repeated headings and follows GitHub link rules.
This skill uses version 9.0.0.

## GitHub heading links

https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax#section-links

GitHub turns headings into links by lowercasing letters, replacing spaces with
hyphens, removing most punctuation, and adding a number when the same link appears
more than once. GitHub also shows its own contents list when a Markdown file has at
least two headings.
